About the Portfolio

Below you will find a selection of our deployed web-based solutions. All applications are conceived under an open-source theoretical and conceptual framework, leveraging open tools and well-established standards tailored to each specific challenge. We operate across domains such as multi-criteria analysis (AHP/Saaty), extraction and processing of geospatial data (OpenStreetMap, DEM, Shapefiles, GeoTIFFs) with cloud computing (Google Earth Engine), WebGIS (Leaflet/OpenLayers, QGIS Server, GeoServer, PostGIS), and logistics/territorial and infrastructure planning — always with reproducible pipelines (Python/GeoPandas/Rasterio, ETL, Git/Docker version control) and integration with systems such as SIGMA-PLI and DER/SP.

Reinforcing our commitment to science, we combine scientific principles — modeling, inference, and data governance/quality — with technology — modern architectures, interoperability, and automation — to deliver transparent, auditable, and scalable solutions. This rigorous association between theory and tooling enhances the reliability of our analyses and prepares our products for large volumes and diverse datasets, meeting a wide range of demands.

Production Solutions

SIGMA - AHP Calculator

Multi-criteria analysis system using the Analytic Hierarchy Process (AHP) method by Saaty. Supports pairwise comparisons of up to 20 criteria with automatic weight calculation and consistency indices. Generates interactive graphical visualizations and exports results in PDF, CSV, and XLSX formats.

AHP/Saaty JavaScript Multi-Criteria Analysis Visualization
Launch Application

Road Jurisdictionalization DER/SP

Methodological decision-support tool for the jurisdictionalization of road elements under DER/SP. Analyzes 1,247 roads using AHP with environmental, socioeconomic, and territorial integration criteria. Generates spatial favorability (IFM), socioeconomic (IFS), and infrastructure quality (IQI) indicators.

AHP Geoprocessing Infrastructure DER/SP
Launch Application

Indicator Adherence Calculator

PLI SIGMA system for methodological assessment of indicators through seven analytical criteria: conceptual proximity, causal mechanism, empirical validity, specificity, sensitivity, measurability, and cost-effectiveness. Classifies indicators into four adherence levels and supports CSV upload for batch analysis.

Multi-Criteria Analysis Indicators CSV Upload JavaScript
Launch Application

FAD - SmartGeo (OSM Extractor)

Intelligent geoprocessing tool for automated extraction of vector data from OpenStreetMap via API. Enables extraction of roads, rivers, and municipal boundaries using polygon masks. Generates segmented buffers with configurable width and exports results as compressed ESRI Shapefiles (.shp) ready for use in GIS environments.

OpenStreetMap API Shapefile Buffer Analysis Python
Launch Application

WebGIS - Jurisdictionalization

Interactive WebGIS system built with Leaflet for visualization and spatial analysis of road elements subject to jurisdictionalization. Integrates multiple thematic layers (administrative boundaries, environmental restrictions, infrastructure, and projects). Features layer control, measurement tools, and three basemaps (OpenStreetMap, ESRI Street, and Satellite).

Leaflet WebGIS Spatial Analysis JavaScript
Launch Application

Shipper Interview Form

Structured web system for collecting and characterizing freight logistics data in the State of São Paulo. Captures information on products, origins, destinations, transport modes, costs, and decision factors (cost, time, reliability, safety, capacity). Includes modal sensitivity analysis, data validation, and JSON export for downstream processing.

Logistics Data Collection Modal Analysis JavaScript
Launch Application

FAD-Slope (Google Earth Engine)

Geospatial application powered by Google Earth Engine for large-scale terrain slope analysis and visualization. Utilizes Digital Elevation Models (DEM) for automated slope calculation, enabling identification of areas with varying topographic gradients. An essential tool for environmental studies, territorial planning, risk assessment, and infrastructure feasibility analysis.

Google Earth Engine DEM Topographic Analysis Cloud Computing
